# PeerReview
 Веб-приложение с автотестами, проверяющее код на несоответствие стандартам языка программирования и требованиям преподавателя.
 В рамках учебной практики была поставлена задача разработки системы, которая бы автоматизировала процесс оценки программных работ, предоставляя студентам возможность получать быстрые и подробные отчёты о качестве своих решений. Такой подход способствует более глубокому усвоению материала и развитию навыков самостоятельной работы.

 Выполнены следующие задачи:
* Регистрация
* Основное меню
* Создание курса и заданий курса
* Отправка и проверка кода (линтеры, требования преподавателя, автотесты)
